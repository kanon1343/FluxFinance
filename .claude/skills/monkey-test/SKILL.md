# 探索的テスト

重点対象: $ARGUMENTS（未指定ならアプリ全体）

## 準備

1. `pnpm dev` をバックグラウンドで起動し、`http://localhost:3000` が応答するまで待つ。
2. 探索用のスクリプトは `e2e/explore/`（gitignore 済み）に置き、`pnpm exec playwright test e2e/explore --reporter=line` で実行する。

## 探索の進め方

- まず画面構造を把握する。`page.getByRole` で操作できる要素を列挙し、要点だけを出力する小さなスクリプトを書く。HTML 全体やスクリーンショットを大量に出力しない。
- 次の観点で操作シナリオを数本ずつ書いて実行し、結果を見て次のシナリオを決める。
  - 通常の操作: 銘柄カードのクリック、チャートモーダルの開閉、期間の切り替え
  - 異常な操作: 連打、高速な画面遷移、ウィンドウサイズの変更（モバイル幅）、キーボードだけでの操作、Esc キー
  - API の失敗: `page.route` で `/api/market` や `/api/history` を 500 エラー・遅延・空データにした時の表示
  - 監視: `page.on('console')` と `page.on('pageerror')` で、コンソールエラーと例外を記録する
- 操作は全部で30〜50アクション程度を目安にする。同じ種類の操作を繰り返さない。

## 報告

- 見つけた問題ごとに、再現手順・期待した動作・実際の動作・該当しそうなコード（`path:行番号`）を書く。
- 再現できた問題は `e2e/` に回帰テストとして追加する（修正は頼まれてから行う）。
- 最後に、`pnpm dev` を停止し、`e2e/explore/` を空にする。
